# Convite Rômulo & Viviane

Convite virtual do casamento de Rômulo Maciel e Viviane Gadelha (06/11/2027, Niterói), publicado com GitHub Pages.

## Estrutura

| Caminho | O que é |
|---|---|
| `questionario/` | Questionário para os noivos (fase 1). Funciona no celular e no desktop. |
| `apps-script/` | Script do Google Sheets que recebe as respostas. Instruções em [apps-script/README.md](apps-script/README.md). |
| `index.html` | Por enquanto redireciona para o questionário. Depois vira o convite. |

## Fases

1. Questionário para os noivos
2. Catálogo de estilos com votação
3. Save the date, convite e confirmação de presença (RSVP)

## Rodar localmente

Abra `questionario/index.html` no navegador. Não tem build.
